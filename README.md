# mobile-app

Frontend einer Chat-Anwendung für Gaming Communities mit integrierter Achievement-Anzeige, entwickelt im Rahmen des Moduls *Mobile Apps und User Experience* an der *Hochschule Esslingen*. 

## Überblick & Funktionen
* **Echtzeit-Messaging:** Senden und Empfangen von Nachroichten über REST-API mittels Axios.
* **Benutzeroberfläche:** Chat-Verläufe, Kontaktliste, Login-Screen und weitere Features, wie Dark-Mode und Errungenschaften
* **Tech-Stack:** Vue.js, CSS 

## Hinweise zum Backend
Das zugehörige Backend (Server & Datenbank) wurde im Rahmen der Lehrveranstaltung hochschulseitig bereitgestellt und ist nicht Teil dieses Repositories. da Der Hochschul-Server außerhalb des Semesters nicht mehr öffemtlich erreichbar ist, lässt sich das Frontend ohne eigenes Mock-Backend aktuell nur eingeschränkt (UI-Ansicht) ausführen.
